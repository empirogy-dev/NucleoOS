# Marca de NucleoOS

El átomo de NucleoOS, listo para usar. El núcleo eres tú.

## Colores
- Verde salvia (principal): `#8FAF9B`
- Crema (fondo): `#F7F3EA`
- Tinta (texto): `#2F3A35`
- Terracota (acento): `#D9A38F`

## Archivos

| Archivo | Tamaño | Para qué |
|---|---|---|
| `perfil-redes-verde.png` | 1080 | Foto de perfil de Instagram, Facebook, TikTok |
| `perfil-redes-crema.png` | 1080 | Igual, pero fondo crema con átomo verde |
| `icono-app-verde.png` | 1024 | Ícono de app, esquinas redondeadas |
| `logo-verde-transparente.png` | 1024 | Sobre fondos claros (documentos, presentaciones) |
| `logo-blanco-transparente.png` | 1024 | Sobre fondos oscuros o fotos |
| `logo-tinta-transparente.png` | 1024 | Versión oscura, para impresión |
| `favicon-32.png` | 32 | Pestaña del navegador |

Se regeneran con `scratchpad/logo.html` si hace falta otro tamaño o color.
